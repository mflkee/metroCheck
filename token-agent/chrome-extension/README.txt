Расширение ARSHIN Token Relay для Chrome
==========================================

ЧТО ДЕЛАЕТ
-----------
Это расширение работает на сайте https://fgis.gost.ru/
После входа в личный кабинет оно находит JWT-токен в localStorage/sessionStorage
и отправляет его на локальный агент токена:
   http://127.0.0.1:8003/token/callback

УСТАНОВКА В CHROME
------------------
1. Открой Chrome и перейди в управление расширениями:
   chrome://extensions/

2. Включи "Режим разработчика" (переключатель в правом верхнем углу).

3. Нажми "Загрузить распакованное расширение".

4. Выбери папку chrome-extension из этой папки.

5. Расширение появится в списке. Убедись, что оно включено.

ПРОВЕРКА
---------
1. Войди в личный кабинет ФГИС "Аршин" на https://fgis.gost.ru/
2. Агент токена должен быть запущен (run.cmd)
3. В папке SynologyDrive\tokens должен появиться файл arshin-token.json

ФАЙЛЫ РАСШИРЕНИЯ
----------------
manifest.json   - настройки расширения для Chrome
background.js   - фоновый обработчик, отправляет токен агенту
content.js      - скрипт, который читает токен на странице Аршина

ЕСЛИ НЕ РАБОТАЕТ
----------------
- Убедись, что агент запущен (run.cmd открыт и без ошибок).
- Проверь адрес: http://127.0.0.1:8003/health должен открываться в браузере.
- Убедись, что расширение включено на chrome://extensions/
- Открой консоль на странице fgis.gost.ru (F12 -> Console),
  должны быть сообщения [ARSHIN] Token found.
