# Задача: нечёткий поиск серийных номеров + верификация

## Проблема

AI ошибается в 1-2 цифрах серийного номера (4335 → 4336, 8 → 3, O → 0). Exact match не срабатывает → warning "No calibration found". По факту протокол есть.

## План реализации

### Шаг 1: Репозиторий — метод поиска всех серийных номеров за месяц

**Файл:** `backend/app/repositories/calibration_repository.py`

Добавить метод:
```python
async def get_all_serials(self, year: int, month: int) -> list[str]:
    """Все серийные номера калибровок за месяц."""
```

**Файл:** `backend/app/repositories/protocol_data_repository.py`

Добавить метод:
```python
async def get_all_serials(self, year: int, month: int) -> list[str]:
    """Все серийные номера протоколов за месяц."""
```

---

### Шаг 2: Утилита — функции нечёткого поиска

**Файл:** `backend/app/services/matching_utils.py` (новый)

```python
def normalize_serial(serial: str) -> str
def fuzzy_find_serial(target: str, candidates: list[str], threshold: float = 0.75) -> list[tuple[str, float]]
def verify_candidate(protocol: ProtocolData, calibration: Calibration) -> dict
```

- `normalize_serial` — перенести из `check_service.py` (гомоглифы)
- `fuzzy_find_serial` — difflib.get_close_matches, порог 0.75
- `verify_candidate` — сравнение device_name, verifier, date, protocol_number, result
