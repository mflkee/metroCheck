# Контекст для LLM: тестирование token-agent на Windows

## Постановка задачи

Нужно настроить и протестировать передачу токена Аршина (ФГИС Росаккредитация, `https://fgis.gost.ru`) от браузера Chrome/Yandex в локальный файл на Windows-ПК.

Процесс в продакшене:
1. Зонов логинится в личном кабинете Аршина.
2. JWT-токен появляется в `localStorage`/`sessionStorage` браузера.
3. Chrome-расширение автоматически находит JWT и отправляет локальному агенту на `http://127.0.0.1:8003`.
4. Python-агент записывает токен в JSON-файл внутри папки Synology Drive.
5. Synology Drive Client синхронизирует файл на сервер.
6. Серверный backend/metroGen забирает токен из файла.

Пользователь уже трижды пытался настроить, но возникали ошибки: агент не запускался, расширение не работало. Нужно максимально покрыть обработкой ошибок и убедиться, что в реальной системе токен будет записан в Synology.

## Что сделано

Создана production-ready версия стека в папке `win_test`:

- `server.py` — Python-агент на стандартной библиотеке.
- `run.cmd` / `setup.cmd` — запуск и первичная настройка на Windows.
- `test_env.py` — проверка окружения без запуска сервера.
- `watch_token.py` — мониторинг файла токена.
- `check_token_sync.py` — проверка синхронизации с сервером.
- `chrome-extension/` — Chrome-расширение с retry и сканированием storage.
- `fake-arshin.html` + `serve_fake_page.py` — тестовая страница для отладки без входа в Аршин.
- `.env` — текущие настройки для тестового ПК пользователя (`mflkee`).
- `.env.example` — шаблон для ПК Зонова.
- `README.md` — полная инструкция.

## Ключевые доработки надежности

1. Агент проверяет окружение перед стартом: папка, права на запись, свободен ли порт.
2. Логирование в `token-agent.log` и в консоль.
3. Retry при занятом порте (3 попытки).
4. Атомарная запись файла через `.tmp`.
5. При старте агент загружает существующий токен из файла.
6. Расширение имеет очередь и повторную отправку, если агент был выключен.
7. Popup расширения показывает статус агента, сканирует `localStorage`, позволяет отправить тестовый токен.
8. Поиск JWT в storage по продакшен-списку ключей: `u`, `user`, `profile`, `auth`, `token`, `accessToken`, `arshin_token`.

## Найденные проблемы и решения

### Проблема 1: порт 8003 был занят зомби-процессом Python

Пользователь закрыл все процессы, порт освободился.

### Проблема 2: fake-arshin.html открывался как `file://`

Content-script расширения не запускается на `file://`. Решение: добавлен `serve_fake_page.py`, который отдает страницу по `http://127.0.0.1:8080/fake-arshin.html`.

### Проблема 3: Windows Store-заглушка `python`

Команда `python` в системе не работает (код 9009). Решение: `run.cmd` ищет Python в нескольких местах, включая путь из pgAdmin, или нужно установить Python с `python.org`.

### Проблема 4: путь с пробелами и кириллицей в `.env`

Решение: путь берется в кавычках, парсер `.env` убирает кавычки. Проверено: файл успешно записывается по пути `C:\Users\mflkee\SynologyDrive\2_Документы внутреннего происхождения\2_19 Протоколы\tokens\test\arshin-token.json`.

## Как проверить сейчас

1. Запустить `run.cmd` из папки `win_test`.
2. Установить расширение из `chrome-extension` в Chrome/Yandex (`chrome://extensions/` → режим разработчика → загрузить распакованное).
3. Зайти на `https://fgis.gost.ru/` и авторизоваться.
4. Проверить файл `arshin-token.json` в Synology-папке.

Если автоматика не сработала — нажать на иконку расширения → **"Сканировать localStorage страницы"**.

## Для переноса на ПК Зонова

1. Скопировать папку `win_test` на ПК Зонова.
2. Изменить `.env`:
   ```env
   TOKEN_FILE_PATH="C:\Users\Zonov\SynologyDrive\tokens\arshin-token.json"
   TOKEN_AGENT_HOST=127.0.0.1
   TOKEN_AGENT_PORT=8003
   TOKEN_AGENT_LOG=token-agent.log
   ```
3. Убедиться, что Synology Drive Client установлен и синхронизирует папку `tokens`.
4. Запустить `run.cmd`.
5. Добавить `run.cmd` в автозагрузку Windows (при необходимости).

## Если что-то не работает

1. Смотреть `token-agent.log`.
2. Открыть консоль расширения: `chrome://extensions/` → "Фоновая страница" / "service worker" у расширения.
3. Запустить `python test_env.py` для проверки окружения.
4. Проверить, в каком ключе `localStorage` лежит JWT на `fgis.gost.ru`, и добавить ключ в `chrome-extension/content.js` в `TOKEN_KEYS`.
