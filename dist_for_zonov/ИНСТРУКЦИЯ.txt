# ARSHIN Token Relay - Инструкция для установки

## Что это?
Набор утилит для автоматической передачи токена АРШИН с вашего компьютера на сервер МКАИР (Тюмень).

Компоненты:
- `token-agent.exe` - локальный сервер, который хранит токен и отдаёт его по запросу
- `chrome-extension/` - расширение для Chrome, которое читает токен из АРШИН

## Шаг 1. Netbird (VPN)

Вам должно прийти приглашение на email от Netbird.

1. Откройте письмо с приглашением
2. Перейдите по ссылке из письма
3. Зарегистрируйтесь или войдите (через Google/GitHub/email)
4. Скачайте Netbird для Windows: https://github.com/netbirdio/netbird/releases/latest
   (или напрямую: https://app.netbird.io/install)

5. Установите Netbird и запустите
6. Нажмите "Connect" - откроется браузер для авторизации
7. После успешного подключения в трее появится иконка Netbird

Сообщите администратору, что вы подключились к Netbird. Он проверит, что вы видите друг друга в сети.

## Шаг 2. Открыть порт 8003 в Windows Firewall (ОБЯЗАТЕЛЬНО!)

По умолчанию Windows блокирует все входящие соединения. Без этого шага сервер не сможет достучаться до token-agent.

### Способ 1 (через командную строку, рекомендуется):

1. Нажмите `Win+X` → выберите **Windows PowerShell (Администратор)** или **Терминал (Администратор)**

2. Выполните эту команду (скопируйте полностью и вставьте правой кнопкой мыши):

```powershell
New-NetFirewallRule -DisplayName "Allow Netbird ARSHIN Agent" -Direction Inbound -Protocol TCP -LocalPort 8003 -Action Allow -RemoteAddress 100.64.0.0/10
```

Эта команда разрешает входящие соединения на порт 8003 только из сети Netbird (`100.64.0.0/10`), а не из всего интернета.

### Способ 2 (через графический интерфейс):

1. `Win+R` → введите `wf.msc` → Enter
2. В левой панели выберите "Правила для входящих подключений"
3. В правой панели нажмите "Создать правило"
4. Тип правила: **Порт** → Далее
5. Протокол: **TCP** → Указанные локальные порты: `8003` → Далее
6. Действие: **Разрешить подключение** → Далее
7. Профили: оставьте все отмеченными → Далее
8. Имя: `ARSHIN Agent (Netbird)` → Готово

## Шаг 3. Запустить token-agent

1. Создайте папку `C:\tools\arshin-agent\` (или любую другую, куда у вас есть доступ)

2. Скопируйте `token-agent.exe` в эту папку

3. Запустите `token-agent.exe` двойным кликом
   - Откроется окно консоли
   - Вы увидите что-то вроде:
   ```
   INFO:     Started server process [12345]
   INFO:     Waiting for application startup.
   INFO:     Application startup complete.
   INFO:     Uvicorn running on http://0.0.0.0:8003 (Press CTRL+C to quit)
   ```
   - Это значит, агент запущен и слушает порт 8003

### Для автозагрузки при старте Windows:

1. Нажмите `Win+R`, введите `shell:startup`, нажмите Enter
2. Создайте ярлык на `token-agent.exe`
3. Перетащите этот ярлык в открывшуюся папку Startup

Теперь агент будет запускаться автоматически при каждом включении компьютера.

## Шаг 4. Установить расширение в Chrome

1. Откройте Chrome и перейдите по адресу: `chrome://extensions`

2. В правом верхнем углу включите "Режим разработчика"

3. Нажмите кнопку "Загрузить распакованное расширение"

4. Выберите папку `chrome-extension` из этого архива

5. Расширение "ARSHIN Token Relay" появится в списке

## Шаг 5. Проверка

### Проверка из командной строки (локально):

Откройте PowerShell и выполните:

```powershell
Invoke-RestMethod http://127.0.0.1:8003/health | ConvertTo-Json
```

Должно вернуться: `{"status":"ok","has_token":false}`

### Проверка когда вы залогинились в АРШИН:

1. Откройте сайт АРШИН: https://fgis.gost.ru/fundmetrology/cm/lk

2. Войдите через Госуслуги (если ещё не вошли)

3. Посмотрите в окно консоли `token-agent.exe`
   - Там должно появиться сообщение:
   ```
   [token-agent] Token received — u/localStorage: eyJ...
   ```

4. Если это есть, значит всё работает. Расширение поймало токен и передало локальному агенту.

### Проверка доступности из сети Netbird:

Администратор проверит, что может достучаться до вашего компьютера по Netbird IP на порт 8003.

## Как это работает

```
┌─────────────────────────────────────────────────────────────────────────┐
│                         Ваш компьютер (Windows)                           │
│                                                                          │
│  Chrome с расширением                                                    │
│       ↓ каждые 3 сек проверяет localStorage на fgis.gost.ru            │
│       ↓ находит токен → отправляет на 127.0.0.1:8003                  │
│       ↓                                                                  │
│  token-agent.exe :8003 ◄────────────────────────────────────────────┐   │
│       ↓ сохраняет токен в памяти                                      │   │
│       ↓                                                                │   │
│  Windows Firewall (разрешён порт 8003 для 100.64.0.0/10)            │   │
│       ↓                                                                │   │
└───────┬────────────────────────────────────────────────────────────────┘   │
        │                                                                     │
        │ Netbird mesh VPN (шифрованное P2P соединение)                     │
        │                                                                     │
┌───────▼────────────────────────────────────────────────────────────────┐   │
│                      Сервер МКАИР (mkair-server)                         │   │
│                                                                          │   │
│  Backend (Python/FastAPI)                                                │   │
│       ↓                                                                  │   │
│  Запрашивает токен: POST http://<ваш-netbird-ip>:8003/token/request    │◄──┘
│       ↓                                                                  │
│  Получает токен → использует для запросов в ЛК АРШИН                   │
└──────────────────────────────────────────────────────────────────────────┘
```

1. Когда вы заходите на `fgis.gost.ru` и логинитесь через Госуслуги, в браузере в localStorage появляется JWT-токен

2. Расширение Chrome каждые 3 секунды проверяет localStorage на наличие токена

3. Когда токен найден, расширение отправляет его на `http://127.0.0.1:8003/token/callback`

4. `token-agent.exe` сохраняет токен в памяти

5. Когда серверу МКАИР нужен токен для запросов в личный кабинет АРШИН:
   - Он обращается по Netbird к вашему IP на порт 8003
   - `POST http://<ваш-netbird-ip>:8003/token/request`
   - token-agent отдаёт сохранённый токен

6. Токен живёт ~1 час. Когда вы заходите на АРШИН следующий раз - токен автоматически обновляется.

## Порты

- `8003` - порт token-agent (должен быть доступен через Netbird)

## Безопасность

- Расширение имеет доступ ТОЛЬКО к сайту `fgis.gost.ru` (см. `manifest.json`)
- Токен отправляется ТОЛЬКО на `127.0.0.1:8003` (локально на вашем компьютере)
- Сервер МКАИР получает доступ к токену ТОЛЬКО через зашифрованное соединение Netbird
- Правило Firewall разрешает доступ ТОЛЬКО из сети Netbird (`100.64.0.0/10`), а не из всего интернета
- Никакие данные не отправляются куда-либо, кроме как через Netbird

## Полезные команды PowerShell

### Проверить статус Netbird:
```powershell
netbird status
```

### Проверить, работает ли token-agent локально:
```powershell
Invoke-RestMethod http://127.0.0.1:8003/health
```

### Проверить, открыл ли порт Firewall:
```powershell
Get-NetFirewallRule -DisplayName "*ARSHIN*"
```

### Послушать, кто подключается (для отладки):
В окне token-agent вы будете видеть входящие запросы с логами.

## В случае проблем

1. Убедитесь что Netbird запущен и показывает "Connected"
2. Убедитесь что token-agent.exe запущен и окно консоли не закрыто
3. Проверьте Windows Firewall - порт 8003 должен быть открыт
4. Проверьте что расширение установлено в Chrome
5. Попробуйте перезайти на сайт АРШИН и заново залогиниться через Госуслуги
